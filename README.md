# ChessCore (Chess_Linux)

A Tiny Core Linux remaster with IceWM and free chess GUIs and engines (XBoard, PyChess, Scid, ChessX, GNU Chess, Stockfish, Crafty, ...).

    sh scripts/fetch-packages.sh   # download .tcz extensions + deps
    sh scripts/build-iso.sh        # build/chesscore-*.iso

GitHub Actions builds the ISOs automatically. See [docs/scripts.md](docs/scripts.md).
