# Chess game data

`lichess_db_standard_rated_2013-01.pgn.zst` - January 2013 games from the
[Lichess open database](https://database.lichess.org) (about 120k rated standard games),
released under **CC0**. Decompress with `zstd -d` (the zstd package is in Tiny Core) and open the
resulting `.pgn` in Scid, ChessX, PyChess or Lucas Chess.

More months (much larger) are listed at <https://database.lichess.org>.
